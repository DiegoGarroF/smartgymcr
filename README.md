# smartgymcr

Landing de Smart Gym CR migrada a Astro.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Estructura

- `src/pages/index.astro`: pagina principal en Astro
- `src/styles/landing.css`: estilos de la landing
- `public/scripts/landing.js`: animaciones e interacciones del sitio

## Notas

- Los archivos `smartgymcr-landing.html` y `smartgymcr-landing-v2.html` se mantienen como referencia del HTML original.
- El build genera la salida estatica en `dist/`.
